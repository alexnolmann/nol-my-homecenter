# Безопасность установки и публикации

Этот репозиторий содержит исходный код и шаблоны. Он не содержит рабочих учётных данных, локального CA, ключей подписи, базы, фото и истории сопряжения устройств.

- Корень веб-сервера — только `server/public_html`, не корень репозитория.
- `server/private` — опубликованный PHP-код вне webroot. `server/private/config/local.php` — личная локальная конфигурация, она никогда не публикуется.
- Ключ `.local/h2/secrets/master.key` хранится отдельно от базы; потеря ключа делает зашифрованные настройки недоступными. Не генерируйте новый ключ вместо утраченного для существующей базы.
- `server/storage`, музыкальная библиотека, резервные копии, `.osp`, `.env*`, локальные TLS-сертификаты и Android keystore не должны попадать в коммиты, релизы и Docker build context.
- HTTP в локальной сети — осознанный opt-in с нешифрованными паролями и токенами. В недоверенной сети используйте HTTPS.
- Не используйте production-базу для тестов. Наборы с MySQL меняют данные в отдельной схеме с именем `*_test` и отдельным пользователем.
- Debug-пробы предназначены для диагностики; для обычной установки собирайте release. Публичный корневой сертификат в `res/raw` не является вашим локальным CA.

Перед публикацией выполните `php tools/check-public.php` и проверьте `git status`, diff и будущий архив коммита. Проверка имён и известных форматов секретов не заменяет просмотр содержимого: она не умеет распознавать любой произвольный пароль.

Если обнаружена утечка рабочего секрета, отзовите/замените его. Удаление строки в новом коммите не удаляет её из старой истории. Не присылайте секреты в публичные issues или логи.
