# Display typography

Roboto Condensed Black, static weight 900, bundled for Android 4.4 (no variable-font APIs).
Source: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/robotocondensed).
Upstream file: `RobotoCondensed[wght].ttf`, SHA-256 `dace262afcee68a5276f200d8026c57221735c0118ab5fda8c2c0d3dc409a8d0`.

Copyright 2011 The Roboto Project Authors. Distributed under SIL OFL 1.1;
see [OFL-RobotoCondensed.txt](OFL-RobotoCondensed.txt).

Reproduce with `tools/design/build-poster-font.py` using fonttools 4.67.0.
The subset retains Latin, Cyrillic, punctuation, currency and minus symbols.
The classic design still uses system fonts.

## Poster home numbers

Anton Regular is used only for the large clock, temperatures and currency numbers
on the Neo Poster home in both colour modes. Other poster screens keep Roboto Condensed.
Source: [Google Fonts / Anton](https://github.com/google/fonts/tree/main/ofl/anton),
upstream `Anton-Regular.ttf`, bundled unmodified (170,812 bytes).
Copyright 2020 The Anton Project Authors; SIL OFL 1.1, see [Anton-OFL.txt](Anton-OFL.txt).
The local static TTF works offline on API 19.
