# Архитектура

Android-клиент использует Java / Android Views и поддерживает API 19. WebView не является основой интерфейса. Кэш последних сводок ограничен по размеру; при потере сервера интерфейс сохраняет доступные данные и показывает состояние источника. Настройки оформления, яркости и ночного режима локальны для планшета.

Сервер — PHP 8.4, PDO/MySQL, веб-панель и фоновый сборщик. Доменный код находится в `server/private/app`, миграции — в `server/private/migrations`. Nginx должен видеть только `server/public_html`. Composer автозагружает PHP-код; `server/vendor` создаётся при установке.

`server/bin/console.php maintenance` выполняет обслуживание и сбор данных. Он нужен отдельно от веб-процесса. Провайдеры погоды, курсов ЦБ и котировок Мосбиржи формируют серверные снимки; клиент получает нормализованный API v1. JSON-примеры и схема находятся в `contracts/v1`.

Радиостанции — сохранённые адреса потоков: медиацентр не ретранслирует радио через свой сервер. Музыка индексируется по папкам и отдаётся по авторизованным Range-запросам. На Android старые HTTPS-ограничения обходит ограниченный loopback-мост, сохраняющий проверку серверного сертификата. Одновременно активен только один источник аудио.

Фотографии загружаются и подготавливаются сервером; приложение получает ограниченные изображения и миниатюры. Пользовательские файлы хранятся в `server/storage`, музыка может находиться вне дерева проекта. Эти каталоги и их резервные копии не являются исходным кодом.

Комнатные Xiaomi LYWSD03MMC опрашиваются локально по BLE, затем измерения синхронизируются с сервером. Конфигурация привязана к планшету. Чтение при выключенном экране ограничено; работа A2DP и BLE зависит от старого Bluetooth-стека устройства.

Администратор входит по сессии с CSRF-защитой; планшет связывается по одноразовому коду и получает отзываемый токен с правами. Секреты интеграций шифруются отдельным Sodium-ключом вне базы. Без этого ключа восстановление одной только базы недостаточно.
