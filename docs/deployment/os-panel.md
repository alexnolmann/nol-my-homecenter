# OSPanel / Windows

Нужны OSPanel 6, Nginx, PHP 8.4 и MySQL 8.4. Установите зависимости и настройте базу по [инструкции установки](../getting-started.md). Корень сайта — `server/public_html`.

Поместите checkout в каталог проектов OSPanel или добавьте его родительский каталог в поиск проектов. Из корня выполните, подставив **свои** DNS-имя и LAN-IP:

```powershell
php deploy/osp/prepare.php panel.miniw 192.168.50.10
```

Будут созданы игнорируемые `.osp/project.ini`, `.osp/env.ini` и Nginx-фрагмент. Отличающиеся настройки не перезаписываются. Добавьте имя сайта в домашний DNS, разрешите доступ по HTTP из домашней сети и перезапустите OSPanel. Шаблоны находятся в `deploy/osp`.

HTTP-админка требует явного `MC_HTTP_HOST`, равного DNS-имени сайта. В development можно задать `transport.http_host` в локальном PHP-конфиге. Nginx-шаблон устанавливает FastCGI `MC_ADMIN_ALLOWED=1`; клиентские HTTP-заголовки не дают этого права. Через HTTP учётные данные идут без шифрования, поэтому используйте только доверенную локальную сеть. Для HTTPS предоставьте свой сертификат и соответствующую конфигурацию.

PHP/Nginx должны иметь доступ к `server/storage` и индексируемым музыкальным каталогам. Музыка передаётся внутренним X-Accel-Redirect с поддержкой Range. Не открывайте внутренние файловые маршруты снаружи. Фото обрабатываются GD/EXIF; в шаблоне заданы лимиты загрузки и памяти. Личные фото и MP3 хранятся отдельно от исходного кода.

Запустите `php server/bin/console.php maintenance` отдельно, в том же окружении базы, что и веб-сайт. Проверьте `php server/bin/console.php check`. Затем откройте `http://panel.miniw/admin/`, создайте планшет и код сопряжения. В Android укажите тот же адрес.

`deploy/windows/start.ps1 -OpenServerRoot <путь-к-OSPanel>` — альтернативный изолированный loopback Nginx/PHP-CGI для разработки. Он не настраивает домашний DNS и не публикует HTTP-админку в сеть. Не запускайте его одновременно с другой установкой на тех же портах. Остановка — `deploy/windows/stop.ps1`.

Файл `deploy/linux/nginx-tls.conf` — шаблон переноса на Linux/PHP-FPM. Пути сертификатов, права на музыку и обслуживание процесса сборщика нужно настроить на целевом хосте.
