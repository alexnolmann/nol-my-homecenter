# Контейнерный шаблон

В `deploy/docker` сохранён экспериментальный шаблон Nginx + PHP-FPM + MySQL. **Он не является проверенной готовой production-установкой:** его исполнение на Linux, полный набор новых медиа-маршрутов, права файлов и внешнее HTTPS-завершение нужно проверить на целевом хосте. Основной проверенный путь разработки — OSPanel/Windows.

Создание собственных случайных параметров и запуск:

```powershell
php tools/setup/init-compose.php
docker compose --env-file .local/h1/compose.env -f deploy/docker/compose.yaml up --build
```

`.local/h1/compose.env` не публикуется. Контейнеры используют отдельные Docker volumes базы и runtime, не рабочую базу OSPanel. Выполните миграции, настройте отдельный Sodium-ключ, администратора и TLS перед реальным использованием. Секреты не должны попадать в Dockerfile или образ.

Текущий Nginx-шаблон имеет закрытую администрацию и подходит как исходная транспортная конфигурация, а не как универсальный сервер музыки/фото. Файл `deploy/linux/nginx-tls.conf` показывает отдельный вариант HTTPS и внутренних файловых маршрутов; их нужно согласовать со своей установкой. Не снимайте ограничения доступа простым открытием всего корня проекта.
