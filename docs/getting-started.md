# Установка

## Требования

- Android 4.4 / API 19 или новее; первоначальная проверка выполнена на ASUS K014.
- PHP 8.4: `pdo_mysql`, `curl`, `sodium`, `xml`, `simplexml`, `bcmath`, `gd` с JPEG/PNG и `exif`.
- MySQL 8.4, Composer 2 и веб-сервер с FastCGI и поддержкой Range / X-Accel-Redirect для музыки.
- Для сборки: JDK 17, Android SDK platform 36, build-tools 35.0.0 и Gradle Wrapper из `android/`.

## Сервер

Все команды выполняются из корня публичного checkout. Не используйте рабочие пароли в аргументах команд и в tracked-файлах.

```powershell
composer install --working-dir=server --no-interaction --prefer-dist
php tools/setup/init-local.php
php tools/setup/init-secret-key.php
```

Первая команда конфигурации создаёт игнорируемый `server/private/config/local.php` со случайным development-токеном. Впишите туда свои параметры `database.host`, `port`, `name`, `user`, `password`. Базу и её пользователя создайте заранее; у пользователя должны быть права для миграций только этой базы. Не публикуйте этот файл.

```php
// Фрагмент local.php, значения заполняются локально.
'database' => [
    'host' => '127.0.0.1', 'port' => 3306,
    'name' => 'home_panel', 'user' => 'home_panel', 'password' => null,
],
```

Затем примените схему:

```powershell
php tools/setup/migrate.php
```

На **новой** базе отдельно выполните [первичную инициализацию сервера](agent-installation.md#3-первичная-инициализация-сервера): миграции не создают идентификатор `app_state.server_id` и фиксированные источники финансов. Без идентификатора первое сопряжение не завершится. Для существующей установки сохраняйте прежний идентификатор и ключи; не заменяйте их новым bootstrap.

Создайте первого администратора интерактивным скриптом PowerShell 7:

```powershell
./tools/setup/bootstrap-admin.ps1 -Login owner -PhpPath php
```

Пароль запрашивается скрыто и поступает в PHP через stdin. Не запускайте development-инициализаторы на существующей рабочей установке без необходимости: обычные планшеты и списки настраиваются в веб-панели.

Настройте сайт по [инструкции OSPanel](deployment/os-panel.md). Для постоянной установки production-конфигурация берёт параметры базы из `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`; development `local.php` не переопределяет production-режим. Ключ шифрования по умолчанию расположен в `.local/h2/secrets/master.key`, либо задаётся `MC_SECRET_KEY_PATH`.

В отдельном процессе с теми же настройками базы запустите:

```powershell
php server/bin/console.php maintenance
```

Проверка готовности:

```powershell
php server/bin/console.php check
```

Ожидается `ready=true`. Веб-процесс сам не запускает фоновый сборщик. Перезапуск после сбоев и автозапуск задаются окружением хоста.

## Планшет

Соберите APK по [инструкции разработки](development.md), установите на устройство. В веб-панели сначала создайте город, затем выдайте одноразовый код подключения с выбранными местом и правами. Реальная запись планшета создаётся при использовании кода. В приложении укажите базовый адрес своего сервера без `/admin/` и введите код. Настройте радиостанции, валюты/акции и каталоги; фото загружайте через панель.

Первая связь BLE-датчика выполняется из раздела «Климат». Колонки сначала сопрягаются в системных настройках Android, после чего их можно выбирать в приложении. Пользовательские сертификаты и серверные API-ключи вы создаёте самостоятельно.

## Резервное копирование

Сохраняйте рабочую MySQL-базу, локальную конфигурацию, отдельный Sodium-ключ, настройки окружения, фото в `server/storage` и музыкальные каталоги. Они не должны попадать в публичный репозиторий. Ключ подписи Android нужен отдельно для обновления уже установленного release-приложения.
